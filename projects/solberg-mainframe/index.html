Solberg Mainframe

A Django application for household inventory tracking, plus a catalog and project tracker for a large LEGO collection.

Role
Author
Users
My family
Stack
Django, Python
Status
Early stage

What it is

Two features share one application because they use the same underlying data model. The first is a storage inventory: what the household owns, which container it is in, and which room that container is in. The second is a catalog of a large LEGO collection with a project and task tracker, recording what is built, what is disassembled, and what is planned.

Where it stands

Early stage. The current open piece is a loader that pulls set and part data from a LEGO catalog API, the same wrapper pattern as my other loader work.
